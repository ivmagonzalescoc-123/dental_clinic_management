3D tooth preview models
-----------------------

Per-tooth GLB files (odontogram/models/teeth/)
Source: DentProSave / 3d-dental-modeling-vaadin-component (Richie Koller)
URL: https://github.com/richiekoller/3d-dental-modeling-vaadin-component
Files: maxillary/mandibular incisors, canines, premolars, and molars (12 templates, cloned per FDI type)

Layout algorithm adapted from the same project (parabolic arch, per-tooth width, open-mouth pivots).

Legacy file: tooth.glb
Source: dentist-dream demo (Igor-Vuk)
URL: https://github.com/Igor-Vuk/dentist-dream
Original file: public/models/tooth-final.glb
(Not used for the 3D preview arch — kept for reference only.)

2D charting uses SVG (svg-chart.js) and is unchanged. The 3D tab is preview-only.
